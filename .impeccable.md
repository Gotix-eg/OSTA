## Design Context

### Users
OSTA serves Egyptian clients, workers, and vendors on mobile. Clients need to book home services quickly, workers need to scan and accept jobs while moving, and vendors need to manage inventory and orders. The app should feel reliable enough for payments, scheduling, location, and Google Play release.

### Brand Personality
Professional, trustworthy, practical. The product should feel like a serious local services platform, not a marketing site or a generic template.

### Aesthetic Direction
Native mobile application with Arabic-first RTL layouts, both light and dark modes, warm OSTA gold as a brand anchor, deep ink neutrals, restrained teal accents for operational states, and clear dashboard surfaces. Avoid WebView-like layouts, oversized marketing hero sections, neon gradients, and decorative clutter.

### Design Principles
- Make core work visible immediately: requests, jobs, orders, inventory, and account status should be easy to scan.
- Keep role-based workflows distinct while sharing a consistent design system.
- Use light and dark themes with equivalent contrast, not just inverted colors.
- Prefer native controls, compact cards, status chips, and clear action hierarchy.
- Every screen should be wired to API data where the backend endpoint exists, with useful loading and empty states.
